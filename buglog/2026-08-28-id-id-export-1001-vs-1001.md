审查发现 banmu-server/data/items_export.json（后台 admin 物品字典源，meta.service.ts loadItemsDict 读取）与客户端游戏库 shuju_json_shujubao/daoju_dang/QuanJuWuPinKu.json 同 ID 不同物：export 1001=向日葵种子，游戏库 1001=兽骨基肥。后台下拉配置的目标 item_id 落库后与游戏内真实物品错位，任务无法完成。修复：新建 tools/sheng_cheng_items_export.py，以游戏库为唯一权威源重建 export（107 条全量，category 数字转 MATERIAL/FLOWER/SEED 等字符串，custom_fields.zhonglei 按消费语义映射 cat4=zhiwu/cat3=huahui/其余=item，icon_path 透传，货币条目补空串）。重建后 1001=兽骨基肥(MATERIAL/item)、5001=桃花种子(zhiwu→seed 进种植下拉)、4001=桃花(huahui→flower 进其余下拉)。本地 Python 校验 107 条+zhonglei 分布 30/30/47；远端 JSON.parse 通过；生产服务重启后健康。当前 119 条 quest_defs 无 item_id 目标，重建无存量数据风险；种子奖励硬编码 5001（游戏 ID 空间）不受影响。
